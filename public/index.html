A private place to write.

  • You open the page and type.
  • It is a local app. Everything you write lives in this browser's own storage, and that is the only copy. There is no server, no account, and nothing is ever sent out.
  • A share link carries the text inside itself. A private link is locked with a seed word that Nanotype never sees.
  • After the first visit it works offline. It installs as an app.
  • It reads and writes plain text and Markdown.
  • Every command has a key. lists them.
  • Every command is in menu, at the bottom.
  • Visits and commands are counted with cookie-free PostHog. The text is never part of that.

Share this document

Nanotype puts the text inside the link itself. Nothing is stored anywhere: not on a server, not by Nanotype. The link is the only copy, and it works for as long as someone keeps it. It cannot be taken back: whoever has the link has the text, as with a file you have sent.

It is a snapshot of the text as it is now, not a shared document: later changes, yours or theirs, do not travel.

  • public linkAnyone who has the link can read the text.
  • private linkThe text is locked with a seed word. Send the seed word another way; without it the link is noise.

A copy that outlives this browser

Your text lives in this browser's own storage. That is private, and it is also fragile: it goes when the browser's data is cleared, and it does not follow you to another device.

On this browser Nanotype can keep a folder up to date as you write: every document as a .md file, and everything in one .json. Pick the folder once; if it is in iCloud or Dropbox, the copy follows you. Its documents folder is Nanotype's: a .md file there that is no longer a document is removed.

  • keep a copy in a folder…Chrome, Edge, Brave on a computer
  • resume the folder copythe browser asks once after a restart
  • stop the folder copythe files stay; nothing more is written
  • export everything as .md (zip)every document as a file, in one .zip
  • export everything as .jsonevery document and setting, for import

On an iPhone or iPad, add Nanotype to the home screen: Safari then keeps its storage instead of clearing it after 7 days.
